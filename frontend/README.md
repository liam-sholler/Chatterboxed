# Chatterboxed: Frontend

Built with React + TypeScript + Vite.

## How it Works

Owns no authoritative logic. Frontend was built using mostly AI. I picked React, TypeScript, Tailwind CSS, and shadcn/ui for the full frontend stack, generated a DESIGN.md / AGENTS.md, and allowed an agent to create reusable component logic and draft frontend code. Explicitly telling it to prefer a modular setup allows themes, consistent design language, and avoids unmaintainable output.
